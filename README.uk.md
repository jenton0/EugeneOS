# EUGENE OS

[English](README.md) | **Українська**

64-бітна операційна система для x86-64, написана з нуля на асемблері та C.
Завантажується через UEFI, читає й пише FAT32, має графічну оболонку в стилі
Windows 3.1, власний стек TCP/IP і вміє **перезбирати сама себе**: порт flat
assembler працює всередині системи й асемблює її власне ядро.

```
EUGENE OS  Version 2.0
(C) 2026 Eugene.  All rights reserved.

Type HELP for a list of commands.

C:\>_
```

## Можливості

**Завантаження**
- Власний UEFI-завантажувач (`format PE64 EFI`) з графічним екраном налаштувань
- Вибір відеорежиму через GOP, дані про процесор, пам'ять і диск, вбудовані заміри
- Коректні `GetMemoryMap` + `ExitBootServices`, зрозумілі екрани помилок замість зависання

**Ядро**
- Long mode (x86-64), розмір екрана береться з GOP під час завантаження
- Обробники винятків 0–31 зі звітом про збій (вектор і `RIP`)
- Таймер на IRQ0 з частотою 1000 Гц, витісняльний планувальник на вісім слотів задач
- Власні сторінкові таблиці: тотожне відображення 0–4 ГБ, некешоване MMIO,
  нульова сторінка й сторінка-вартовий під стеком недоступні
- Розподільник фізичних кадрів, підкачка на вимогу, власний адресний простір
  на кожну задачу, який повністю повертається після виходу
- Клавіатура й миша PS/2 (з колесом), PC speaker

**Файлова система**
- FAT32: читання й запис, підкаталоги, усі копії FAT синхронні
- Файлові дескриптори: `open` / `read` / `write` / `lseek` / `close`
- Тип файлу визначається за вмістом (підпис `EUGN`), розширення — лише запасний варіант
- Дата й час зміни ставляться з годинника CMOS

**Мережа**
- Перелічення PCI, драйвер RTL8139
- ARP, IPv4, ICMP (пінг в обидва боки), UDP, клієнт DHCP, резолвер DNS
- TCP-клієнт із повторною передачею і буфером прийому на 256 КБ
- HTTP/1.0 із `Host:` і перенаправленнями; текстовий веббраузер (`WEB`)

**Текстова консоль ядра**
- Командний рядок у стилі MS-DOS, близько 40 команд
- Вбудований текстовий редактор (файли до 4 МБ, перехід на рядок, двійкові файли лише на перегляд)
- Переглядач тексту, BMP і відео на весь екран

**Графічна оболонка** (`GUI.BIN`)
- `libgui`: вікно — це об'єкт із процедурою повідомлень, як `WndProc`
- Перетягування, зміна розміру за будь-який край, згортання в піктограму,
  розгортання, системне меню
- Кнопки, прапорці, перемикачі, поля вводу, списки, смуги прокрутки, меню,
  модальні діалоги, буфер обміну, часткове оновлення екрана
- Додатки: диспетчер програм, консоль, блокнот, файловий менеджер,
  переглядач зображень, програвач відео, список задач, будь-яка програма у вікні

**Розробка всередині системи**
- Порт flat assembler 1.73: `RUN FASM.BIN KERNEL.ASM KERNEL.BIN`
- `INSTALL` ставить нове ядро, а старе зберігає як `KERNEL.BAK`

## Структура проєкту

```
EugeneOS/
├── build.bat              зібрати все, записати на VHD, запустити QEMU
├── linker.ld              лінкер-скрипт для програм користувача
├── boot/
│   ├── main.asm           UEFI-завантажувач (~2 100 рядків)
│   └── OVMF.fd            прошивка UEFI для QEMU
├── kernel/
│   └── kernel.asm         ядро (~17 000 рядків)
├── libc/
│   ├── entry.c            точка входу програм (CRT0)
│   ├── eugene_libc.c      бібліотека C
│   └── include/
│       ├── stdlib.h       обгортки системних викликів і прототипи
│       └── syscalls.h     сумісність зі старим кодом
├── libgui/                віконна бібліотека (~4 800 рядків)
│   ├── gui.h  gui.c       нижній шар: пікселі, обрізання, шрифт, курсор, черга подій
│   ├── bmp.c              розбір і виведення BMP
│   ├── win.h  win.c       вікна, повідомлення, порядок, фокус, рамки, модальний цикл
│   ├── ctl.c              елементи керування: кнопки, поля, списки, написи
│   └── menu.c             меню та стандартні діалоги
├── userland/
│   ├── shell.c            графічна оболонка
│   └── guidemo.c          демо нижнього шару libgui
├── fasm_port/             порт flat assembler (збирається окремо)
│   ├── BUILD_FASM.bat
│   ├── FASM.ASM           точка входу
│   ├── SYSTEM.INC         платформний шар EUGENE OS
│   ├── MODES.INC          з LINUX/X64 fasm, без змін
│   ├── HELLO.ASM          тестова програма
│   └── *.INC              вихідники fasm (без змін)
├── run_drive/
│   └── startup.nsh        скрипт UEFI shell, що запускає завантажувач
└── docs/                  внутрішня будова й нотатки розробки
```

Самого QEMU в репозиторії немає: поклади `qemu-system-x86_64.exe` у папку
`qemu/` в корені проєкту (git її ігнорує).

## Збірка й запуск

Збірка працює під Windows.

### Що потрібно

| Інструмент | Шлях за замовчуванням |
|---|---|
| flat assembler | `C:\fasm\fasm.exe` |
| MinGW-w64 (gcc, ld, objcopy), GCC 7 або новіший | `C:\mingw64\bin\` |
| QEMU | `.\qemu\` |
| VHD фіксованого розміру з FAT32 | `C:\store\1.vhd`, буква `E:` |

Усі шляхи — змінні на початку `build.bat`.

### Збірка

```
build.bat
```

Скрипт:
1. монтує VHD через `diskpart` (потрібні права адміністратора);
2. асемблює завантажувач у `E:\EFI\BOOT\BOOTX64.EFI`, а ядро — у `E:\kernel.bin`;
3. компілює `libc`, `libgui` і оболонку через GCC;
4. лінкує `GUI.BIN` і `GUIDEMO.BIN` і записує їх на диск;
5. відмонтовує VHD і запускає QEMU з 512 МБ пам'яті та мережевою картою RTL8139.

Мережевий трафік пишеться в `net.pcap`, який відкривається у Wireshark.

### Перші кроки

Коли з'явиться консоль:

```
HELP            список команд
RUN GUI.BIN     запустити графічну оболонку
```

Вийти з оболонки — `File → Exit Windows` у диспетчері програм.

### Прапорці компіляції — не змінювати

```
-ffreestanding -fno-pie -m64 -mno-red-zone -mgeneral-regs-only
-mno-stack-arg-probe -fno-stack-protector -fno-exceptions
-fno-asynchronous-unwind-tables -fno-ident -O2
```

- `-mgeneral-regs-only` — без SSE. Планувальник не зберігає регістри XMM.
- `-mno-red-zone` — обробники переривань пишуть нижче `RSP`.
- `-mno-stack-arg-probe` — інакше MinGW кличе `___chkstk_ms`, якої тут немає.
- `-fno-stack-protector` — інакше GCC кличе `__stack_chk_fail`.

Лінковка йде у два кроки (`ld` у PE, потім `objcopy -O binary`), бо `ld` з
MinGW не вміє писати не-PE файли. Докладніше — у
[docs/internals.uk.md](docs/internals.uk.md#лінковка-програм-користувача).

## Команди консолі ядра

### Файли

| Команда | Дія |
|---|---|
| `LS` | список файлів із розмірами |
| `CD <dir>` | змінити каталог |
| `BACK` | на рівень вище |
| `MKDIR <dir>` | створити каталог |
| `CREATE <file>` | створити файл |
| `RM <file>` | видалити файл |
| `COPY <src> <dst>` | скопіювати файл |
| `REN <old> <new>` | перейменувати файл або каталог |
| `OPEN <file>` | переглянути файл: текст, BMP чи відео, за вмістом |
| `FILE <file>` | показати, яким система вважає тип файлу |
| `EDIT <file>` | редагувати файл |
| `RUN <program> [args]` | запустити програму |
| `INSTALL <file>` | поставити нове ядро, старе зберегти як `KERNEL.BAK` |

### Мережа

| Команда | Дія |
|---|---|
| `PCI` | перелічити пристрої PCI |
| `NETINIT` | ініціалізувати мережеву карту, показати MAC |
| `NETTEST` | ARP-запит до шлюзу |
| `DHCP` | отримати адресу автоматично |
| `IPCONFIG` | показати поточні налаштування |
| `PING` / `PING <ip або ім'я>` | пінг шлюзу, адреси чи імені |
| `NSLOOKUP <host>` | дізнатися адресу за іменем |
| `SETDNS <ip>` | задати DNS-сервер вручну |
| `TCP <ip> <port>` | відкрити й закрити з'єднання (перевірка рукостискання) |
| `GET <host> [path]` | забрати сторінку по HTTP і показати сиру відповідь |
| `WEB <host> [path]` | відкрити сторінку текстом, з переходом за перенаправленнями |

Типовий сценарій: `NETINIT`, `DHCP`, потім `WEB example.com`. Працює лише
звичайний HTTP; про сайти на HTTPS система прямо повідомляє.

### Система

| Команда | Дія |
|---|---|
| `HELP` | список команд |
| `CLS` | очистити екран |
| `INFO` / `CPUINFO` | відомості про систему й процесор |
| `TIME` | поточний час |
| `BEEP` | перевірка PC speaker |
| `MEMMAP` | карта пам'яті й вільні кадри |
| `PAGING` | стан сторінкових таблиць |
| `TASKS` | слоти задач і статистика підкачки |
| `WIN` | намалювати тестове вікно |
| `REBOOT` | перезавантаження |
| `PFTEST` / `NULLTEST` | навмисна відмова сторінки / нульовий покажчик (потрібне перезавантаження) |

### Редактор

| Клавіша | Дія |
|---|---|
| `F2` | зберегти |
| `F3` | перейти на рядок за номером |
| `ESC` | вийти |
| стрілки, `PgUp` `PgDn`, `Home` `End` | рух каретки |
| `Backspace` / `Delete` | стерти символ перед / під кареткою |

У заголовку показано `LINE`, `COL` і `SIZE`. Файл із нульовим байтом
відкривається лише на перегляд, з червоною смугою `BINARY FILE - READ ONLY`.
Шрифт ядра покриває лише ASCII, тому кирилиця показується порожнечею.

## Графічна оболонка

```
RUN GUI.BIN
```

| Вікно | Що вміє |
|---|---|
| Диспетчер програм | піктограми всього, що є в поточному каталозі; підкаталоги відкриваються подвійним кліком |
| Консоль | `HELP CLS VER TIME LIST CD RUN ECHO WEB EXIT`; решта команд іде в ядро (`MEMMAP`, `TASKS`, `PING`, `GET`…) |
| Блокнот | багаторядковий редактор із меню `File` і `Edit`; `WEB <host>` у консолі відкриває сторінку саме тут |
| Файловий менеджер | колонки «ім'я», «розмір», «дата»; відкрити, запустити, копіювати, перейменувати, видалити, створити каталог, властивості |
| Переглядач зображень | BMP у вікні з прокруткою |
| Програвач відео | `.EVD` у вікні, масштаб під розмір вікна, `Пробіл` — пауза |
| Програма у вікні | графічна програма (наприклад, DOOM) малює у вікно, а не на весь екран |
| Список задач | подвійний клік по робочому столу: `Switch To` / `End Task` |

Команди ядра, які забирають екран (`RUN`, `OPEN`, `EDIT`, `WEB`, `WIN`,
`REBOOT`, `CLS`), з консолі оболонки не виконуються.

### Керування

| Дія | Як |
|---|---|
| Перемістити / змінити розмір вікна | тягнути заголовок / край чи кут |
| Згорнути / розгорнути | кнопки праворуч у заголовку |
| Відновити згорнуте | клік по піктограмі внизу екрана |
| Закрити вікно | подвійний клік по квадратику зліва або `Close` у його меню |
| Меню | клік або `Alt` + підкреслена літера |
| Наступний / попередній елемент | `Tab` / `Shift+Tab` |
| Виділити текст | миша, `Shift` + стрілки, `Ctrl+A` |
| Буфер обміну | `Ctrl+C` / `Ctrl+X` / `Ctrl+V` |
| Файловий менеджер | `Enter` відкрити, `F8` копіювати, `Del` видалити, `F5` оновити, `Alt+Enter` властивості |
| Аварійно завершити програму | `Ctrl+Shift+Q` (перехоплює ядро) |

### Піктограми

Формату `.ICO` немає. BMP з тим самим іменем, що й програма, стає її
значком: `APP.BIN` → `APP.BMP`. Підтримано нестиснений BMP на 1, 4, 8, 24 і
32 біти; для значка — до 128×128.

## Самокомпіляція

Система вміє асемблювати власне ядро й будь-яку програму на асемблері.

### Підготовка

1. У `fasm_port/` уже лежать вихідники fasm і платформний шар.
2. Запусти `fasm_port\BUILD_FASM.bat` → `FASM.BIN`.
3. Скопіюй `FASM.BIN` у корінь VHD.

Не підміняй `fasm_port/SYSTEM.INC` файлом із папки `SOURCE\` fasm: той —
для Linux, а наш — порт під EUGENE OS.

### Використання

```
RUN FASM.BIN HELLO.ASM HELLO.BIN
RUN HELLO.BIN
```

Перезбірка ядра, не виходячи з системи:

```
EDIT KERNEL.ASM
RUN FASM.BIN KERNEL.ASM K.BIN
INSTALL K.BIN
REBOOT
```

`INSTALL` спершу зберігає поточне ядро як `KERNEL.BAK`. Відкотитися з робочої
системи: `COPY KERNEL.BAK KERNEL.BIN`. Якщо нове ядро не стартує, старе можна
повернути лише ззовні, змонтувавши VHD.

Ядро, зібране всередині системи, побайтово збігається з тим, що зібрав fasm
під Windows.

Усередині системи збирається лише код на асемблері. Частина на C
(`GUI.BIN`) потребує GCC і збирається на основній машині.

## Відомі обмеження

| Обмеження | Наслідок |
|---|---|
| Немає TLS | сайти на HTTPS не відкриваються |
| Одне TCP-з'єднання за раз, без опцій TCP | немає масштабування вікна, вікно прийому ≤ 64 КБ |
| Мережа на полінгу | марно витрачає такти, під навантаженням можливі втрати пакетів |
| Імена файлів без шляхів | немає `Move`: з файлами можна працювати лише в поточному каталозі |
| Каталог не видалити й не скопіювати | обходу дерева поки немає |
| Відкриті файли тримаються в пам'яті | 8 МБ на файл, до 8 файлів |
| Одне вікно з програмою за раз | ядро вміє сказати лише «дитина жива» |
| `exec` — ланцюжок | програма, що запускає іншу, мусить спершу вийти |
| Планувальник не зберігає стан FPU/SSE | код користувача збирається з `-mgeneral-regs-only` |
| Немає поділу на режими ядра й користувача | усе працює в ring 0, NX вимкнено |
| Стек програми — 2 МБ | межу задає сторінка-вартовий |
| Шрифт ядра лише ASCII | кирилиці в редакторі не видно |
| BMP без RLE | стиснені картинки не відкриються |
| Перевірено лише в QEMU | крок рядка ≠ ширині й формат, відмінний від BGR, на залізі не перевірялися |
