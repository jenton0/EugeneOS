EUGENE OS v2.0 (x86-64)
UA: Опис Проєкту
Огляд
Це аматорська 64-бітна операційна система для архітектури x86-64, розроблена з нуля. Проєкт поєднує низькорівневе ядро на асемблері та високорівневу графічну оболонку на мові C. Система підтримує багатозадачність, роботу з файловою системою FAT32 та має власну віконну підсистему.

Реалізований функціонал
1. Завантажувач (Bootloader)
Тип: UEFI PE64 додаток.

Графіка: Ініціалізація відеорежиму через GOP (Graphics Output Protocol).

Hardware Info: Збір даних про CPU (Brand String), об'єм RAM та параметри диска через UEFI Services.

Завантаження: Пошук та завантаження файлу kernel.bin з розділу FAT32 у пам'ять за адресою 0x100000.

2. Ядро (Kernel)
Архітектура: Монолітне 64-бітне ядро (FASM).

Переривання: Налаштована таблиця IDT, обробка апаратних винятків (0-31) та системних викликів (int 0x80).

Багатозадачність: Таймерний планувальник завдань. Підтримка фонових процесів та ізольованого виконання користувацьких програм.

Пам'ять: Менеджер динамічної пам'яті (Heap) з функціями kmalloc та kfree.

Драйвери:

Диск: ATA PIO режим для читання/запису секторів.

ФС: Повноцінний драйвер FAT32 (читання, створення файлів/директорій, видалення, навігація).

Ввід: Драйвер клавіатури PS/2 (FIFO буфер) та драйвер миші PS/2 (парсинг пакетів, X/Y координати).

Звук: PC Speaker (генерація частот через PIT).

3. Користувацьке середовище (Userland & GUI)
LibC: Власна реалізація стандартної бібліотеки (пам'ять, рядки, форматований вивід sprintf, POSIX-подібні виклики open/read/write).

Віконний менеджер: * Подвійна буферизація (Backbuffer) для усунення мерехтіння.

Підтримка Z-Index (активне вікно поверх інших).

Система подій миші: перетягування вікон (Drag & Drop), згортання, закриття.

Програми:

Console: Командний інтерфейс з історією логів.

Text Editor: Редактор з підтримкою курсору, клавіш навігації та збереження файлів.

File Explorer: Візуальний менеджер файлів з можливістю запуску додатків.
